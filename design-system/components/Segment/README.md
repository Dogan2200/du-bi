# Segment

İki-üç seçenek arasında mod değiştirici: `.seg` içinde `button`'lar, biri `.active`.

- Kap: `surface-2` zemin, `line-2` kenarlık, 3px iç boşluk, 999px yarıçap.
- Pasif düğme: `muted` metin, 30px yükseklik, 12px / 600.
- Aktif düğme: `gold-soft` zemin, `gold-line` iç kenar; metin koyu temada `gold-2`, açık temada `gold-text`.
- Kullanım: "Tutarsal / Miktarsal" gibi tüm raporu etkileyen görünüm modu. Sayfa içi gezinme için Tabs kullanın.

**Tüketici sağlar:** seçenek etiketleri, `role="tablist"` ve `aria-label`.

Statik görünüm; kaynak: `index.html` `.seg`.
