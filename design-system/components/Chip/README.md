# Chip

Bağlam bilgisi taşıyan küçük hap etiket: `.chip` (28px, 11.5px / 600, `surface-3` zemin, `line` kenarlık, `ink-2` metin; içindeki `<b>` `ink`).

- `.chip.gold` — vurgulu bağlam: `gold-soft` zemin, `gold-line` kenar; metin açıkta `gold-text`.
- Birden fazla chip `.chips` kabında 8px aralıkla dizilir.
- Durum (iyi/kötü) bildirmek için değil, bağlam (dönem, adet, kapsam) için. Durum için Pill kullanın.

Statik görünüm; kaynak: `index.html` `.chip`.
