# İkonlar

Kaynağın kendi çizgi ikonları (24×24, dolgusuz, yuvarlak uç). Kodda `currentColor` kullanılır; bu kopyalar `<img>` ile görünsün diye `#14161c` (`ink`, açık tema) mürekkebiyle kaydedildi. Satır içi SVG olarak kullanırken `#14161c` değerini `currentColor` ile değiştirin. Asistan simgesindeki noktalar `#fff8e1` ile çizilir.
